# Dataset setup

The notebook expects the Healthcare Dataset Stroke Data CSV at:

```text
data/raw/healthcare-dataset-stroke-data.csv
```

## Download

1. Download the dataset from the source you used. A commonly used public copy is the [Kaggle Stroke Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset).
2. Extract the archive if needed.
3. Create the `data/raw/` folder in the repository.
4. Place `healthcare-dataset-stroke-data.csv` inside that folder.

The CSV is intentionally excluded from Git by `.gitignore`. Do not upload patient-level data unless you have verified its license and redistribution permissions.

This project is educational only and is not intended for diagnosis or clinical decision-making.
