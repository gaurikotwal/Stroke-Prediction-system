# Visualizations

Run all cells in `notebooks/stroke_prediction.ipynb` after placing the dataset in `data/raw/`.

The notebook creates and saves charts in this folder, including:

- Age distribution
- Stroke distribution and categorical comparisons
- Age-group comparison
- Correlation heatmap
- Model metric comparison
- Confusion matrices
- ROC curve comparison
- Permutation feature importance

The image files are generated locally when the notebook runs. They are not included until you explicitly add and commit them.
